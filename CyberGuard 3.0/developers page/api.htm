CyberGuard API

Integrate our industry-leading threat detection engine directly into your applications. Programmatically scan URLs for phishing, analyze password entropy, and verify file hashes with sub-100ms latency.

Authentication

All API requests require an API Key passed in the header. You can generate a key from your user dashboard.

Authorization: Bearer 676767Myapikey

Rate Limits

To ensure fair usage, we implement rate limiting. Check the response headers.

HeaderDescription
X-RateLimit-LimitRequests allowed per hour.
X-RateLimit-RemainingRequests remaining in current window.

Scan URL

POST /v1/scan/url

Analyzes a URL for phishing, malware, and reputation against 50+ threat databases.

Request Example (cURL)

curl -X POST https://api.cyberguard.com/v1/scan/url \
  -H "Authorization: Bearer {key}" \
  -H "Content-Type: application/json" \
  -d '{"url": "http://suspicious-site.xyz"}'
